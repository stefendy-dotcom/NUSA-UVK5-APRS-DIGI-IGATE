# NUSA UV-K5 APRS

Repository for the NUSA UV-K5 APRS projects by **YF9UAG**.

## Projects

### UV-K5 DIGIPEATER

APRS Digipeater firmware for the Quansheng UV-K5.

- REV1G Normal
- REV1G Standalone
- Bell 202 / AX.25 1200 baud
- WIDE2 n-N digipeating
- Position beacon TOCALL: `APZUAG`

Documentation and firmware:

**[Open UV-K5 DIGIPEATER](./UV-K5%20DIGIPEATER/)**

### UV-K5 IGATE

APRS iGate project using the Quansheng UV-K5 as the RF modem/radio and an ESP32 for Wi-Fi / APRS-IS connectivity.

Current version:

- REV1A
- RF -> APRS-IS field-tested
- UV-K5 + ESP32 compiled firmware packages

Documentation and firmware:

**[Open UV-K5 IGATE](./UV-K5%20IGATE/)**
