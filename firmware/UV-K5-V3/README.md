# NUSA UV-K5 V3 APRS DIGI Firmware

This directory contains APRS Digipeater firmware specifically targeted for the **Quansheng UV-K5 V3** hardware platform.

## Firmware

- `NUSA_UVK5_V3_APRS_DIGI_REV1A_NORMAL.bin` — APRS Digipeater Normal build for UV-K5 V3 hardware.

## SHA256 Checksum


## Flashing Instructions

The V3 binary is provided in raw `.bin` format.

- Use a compatible flashing tool (such as `k5prog`, open web flashers supporting V3 hardware, or your preferred programming suite).
- Ensure your radio has sufficient battery before flashing.
- Put the radio in bootloader/update mode (Hold PTT while powering on).
- Flash `NUSA_UVK5_V3_APRS_DIGI_REV1A_NORMAL.bin`.
