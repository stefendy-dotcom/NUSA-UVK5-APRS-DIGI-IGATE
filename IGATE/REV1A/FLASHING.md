# Flashing Guide — NUSA UV-K5 iGATE REV1A

This document covers both the **UV-K5 firmware** and the **ESP32 binary**.

---

# 1. UV-K5 firmware

File:

```text
firmware/NUSA_UVK5_IGATE_REV1A.packed.bin
```

Use a Quansheng UV-K5 compatible firmware updater that supports `.packed.bin` files.

Official Quansheng support/download page:

https://en.qsfj.com/support/downloads/3268

Look for the UV-K5/UV-K5(8) firmware/update package and install the manufacturer's update tool supplied in that package.

Before flashing:

- Charge the UV-K5 battery sufficiently.
- Use a known-good programming cable.
- Keep a known-good/recovery firmware available.
- Do not remove power or disconnect the cable while writing firmware.

Flash **only**:

```text
NUSA_UVK5_IGATE_REV1A.packed.bin
```

After flashing, power the radio normally, select the intended APRS frequency/VFO and enter APRS/iGate mode (normally Long F2).

# 2. ESP32 — recommended FULL binary

Recommended file:

```text
esp32/NUSA_UVK5_ESP32_IGATE_REV1A_FULL.bin
```

This is a merged **4 MB** image built for classic ESP32 Dev Module / ESP32-WROOM-32 class boards. It contains the bootloader, partition table and application at the offsets generated by Arduino-ESP32 core 3.3.11.

## Using esptool

Install esptool if required:

```text
python -m pip install esptool
```

Connect the ESP32 by USB and identify its COM/serial port.

Windows example:

```text
python -m esptool --chip esp32 --port COM5 --baud 460800 erase-flash
python -m esptool --chip esp32 --port COM5 --baud 460800 write-flash 0x0 NUSA_UVK5_ESP32_IGATE_REV1A_FULL.bin
```

Linux example:

```text
python -m esptool --chip esp32 --port /dev/ttyUSB0 --baud 460800 erase-flash
python -m esptool --chip esp32 --port /dev/ttyUSB0 --baud 460800 write-flash 0x0 NUSA_UVK5_ESP32_IGATE_REV1A_FULL.bin
```

If auto-boot does not work, hold **BOOT**, tap **EN/RESET**, start the flash, then release BOOT when writing begins.

After flashing, reset the ESP32. Connect to:

```text
SSID     : NUSA-IGATE
Password : 12345678
Web      : http://192.168.4.1/
```

Configure station callsign/SSID, Wi-Fi and APRS-IS settings from the web page.

# 3. ESP32 APP-only binary — advanced use

File:

```text
esp32/NUSA_UVK5_ESP32_IGATE_REV1A_APP.bin
```

This file contains only the application image. Use it only if the ESP32 already has the compatible bootloader and partition layout.

Application offset used by this build:

```text
0x10000
```

Example:

```text
python -m esptool --chip esp32 --port COM5 --baud 460800 write-flash 0x10000 NUSA_UVK5_ESP32_IGATE_REV1A_APP.bin
```

If you are unsure, use the **FULL.bin at `0x0`** instead.

# 4. Bahasa Indonesia — firmware UV-K5

Gunakan file:

```text
firmware/NUSA_UVK5_IGATE_REV1A.packed.bin
```

Flash menggunakan updater yang kompatibel dengan Quansheng UV-K5 dan mendukung `.packed.bin`.

Sebelum flash:

- Pastikan baterai UV-K5 cukup.
- Gunakan kabel programming yang baik.
- Simpan firmware recovery yang sudah diketahui bekerja.
- Jangan cabut kabel atau memutus daya selama proses flash.

Setelah selesai, hidupkan radio normal, pilih VFO/frekuensi APRS yang akan digunakan, lalu masuk ke mode APRS/iGate, biasanya dengan Long F2.

# 5. Bahasa Indonesia — ESP32 FULL.bin

File yang disarankan:

```text
esp32/NUSA_UVK5_ESP32_IGATE_REV1A_FULL.bin
```

Ini adalah merged image **4 MB** untuk ESP32 Dev Module / ESP32-WROOM-32. Flash mulai address:

```text
0x0
```

Contoh Windows:

```text
python -m esptool --chip esp32 --port COM5 --baud 460800 erase-flash
python -m esptool --chip esp32 --port COM5 --baud 460800 write-flash 0x0 NUSA_UVK5_ESP32_IGATE_REV1A_FULL.bin
```

Setelah flash, reset ESP32 lalu hubungkan ke:

```text
SSID     : NUSA-IGATE
Password : 12345678
Web      : http://192.168.4.1/
```

Lakukan konfigurasi Wi-Fi, callsign/SSID iGate dan APRS-IS melalui halaman web.

---

# 6. Bahasa Indonesia — APP.bin

`APP.bin` hanya berisi aplikasi dan digunakan jika bootloader serta partition table yang kompatibel sudah ada.

Flash pada:

```text
0x10000
```

Contoh:

```text
python -m esptool --chip esp32 --port COM5 --baud 460800 write-flash 0x10000 NUSA_UVK5_ESP32_IGATE_REV1A_APP.bin
```

Jika ragu, gunakan **FULL.bin pada `0x0`**.
